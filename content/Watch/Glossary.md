This glossary defines the properties used to catalog and query my watch collection in Obsidian using the [Dataview plugin](https://blacksmithgu.github.io/obsidian-dataview/). Additional context and details beyond these properties are written in free-form text in the body of each note.

## Watch Properties

These properties describe specific watches in my collection.

- **brand**: A link to the watch's manufacturer or brand (e.g., `[[Perpetual Watch Co.]]`).
- **model**: The specific name or reference of the watch (e.g., "SC-03").
- **year**: The production year of the watch (optional if unknown).
- **movement**: A link to the movement used in the watch (e.g., `[[Seagull ST1701]]`).
- **import**: The import code stamped on the watch movement or case indicating the manufacturer, brand, or distributor. Commonly used for identification in specific markets or to comply with import/export regulations (e.g., "LWX" for Longines).

## Brand Properties

These properties describe the manufacturer or company behind a watch.

- **established**: The year the brand was founded (e.g., "2004").
- **website**: The official website of the brand (e.g., `https://www.perpetual-watch.com/`).

## Movement Properties

These properties detail the movement used in a watch.

- **manufacturer**: The company that produced the movement (e.g., "Seagull").
- **caliber**: The specific name or identifier for the movement (e.g., "ST1701").
- **type**: The movement type, such as "Automatic", "Manual", or "Quartz".
- **origin**: The country where the movement was manufactured (e.g., "China").
- **jewels**: The number of jewels in the movement (e.g., `20`).
- **rate**: The number of vibrations or beats per hour (e.g., `21600`).
- **reserve**: The power reserve in hours, representing how long the movement will run without winding or power input (e.g., `40`).
- **lift**: The lift angle used in timing and regulation (optional if unknown).
- **hacking**: Whether the movement supports hacking (stopping the second hand during time setting). Boolean value (`true` or `false`).
- **winding**: Whether the movement supports manual winding. Boolean value (`true` or `false`).
